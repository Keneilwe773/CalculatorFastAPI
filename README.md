# FastAPI Calculator

A simple calculator built with FastAPI, Python, HTML, CSS, and JavaScript. This project shows how a FastAPI backend can communicate with a frontend interface using JavaScript Fetch API to perform basic arithmetic operations. (Double check)

## Features:
- Addition (+)
- Subtraction (-)
- Multiplication (x)
- Division (/)

## Technologies Used:
- Python
- FastAPI
- HTML
- CSS
- JavaScript

## API Endpoints
| Name | Description |
|------|-------------|
| /add | Adds two numbers. |
| /subtract | Subtracts one number from another. |
| /multiply | Multiplies two numbers |
| /divide | Divides two numbers with error handling. |
